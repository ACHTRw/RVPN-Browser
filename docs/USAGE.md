# 使用说明

## 1. 两种模式

| 模式 | 行为 |
|---|---|
| 普通模式 | 不设置任何代理，浏览器行为与普通 Chromium 完全一致 |
| RVPN 模式 | 启动 `rvpn-core` 并登录，浏览器流量指向本地 SOCKS5/HTTP 代理，按服务端资源规则分流 |

切换方式（桌面）：点击工具栏 **RVPN** 图标 → 「普通模式」/「RVPN 模式」。
切换是**持久化**的：下次启动会自动恢复上次的模式。

> RVPN 模式下**未命中 RVPN 资源规则的流量直连**，所以公网访问不受影响，也不会变慢。
> 需要"全部流量都走 RVPN"时，在高级设置里打开 `proxyAll`（仅调试用）。

## 2. ZJU 用户

1. 用户类型选择「浙江大学用户」，协议默认 **aTrust**（对应 `vpn.zju.edu.cn`）。
2. 填写学号/工号与上网密码，点击连接。
3. 如出现图形验证码/短信验证码/动态口令，按弹窗提示输入即可。
4. 首次登录成功后会把会话写入 `client_data.json`，后续可免重复认证（可在设置中关闭）。

如需使用 EasyConnect 协议（`rvpn.zju.edu.cn`），在协议下拉框中选择 `easyconnect`。
两者区别：aTrust（L3）走 TCP 隧道、资源由服务端下发；EasyConnect（L2）适合部分旧服务与
非 ZJU 服务器。

## 3. 非 ZJU 用户

1. 用户类型选择「非 ZJU 用户」。
2. 填写服务器地址与端口（例如学校 RVPN 服务器地址，端口通常是 443）。
3. 点击「探测登录方式」，选择探测结果中的一条（登录域 + 认证方式）；
   若目标服务端需要图形验证码，勾选相应选项或直接尝试登录（验证码会弹窗显示）。
4. 选择短信认证时填写手机号（含国家区号）。

核心会自动为这类用户关闭 ZJU 内置规则（`disableZJUConfig`、`skipDomainResource`），
并用服务端下发的资源决定分流。

## 4. 交互式认证

| 类型 | 界面 | 说明 |
|---|---|---|
| 文本图形验证码 | 图片 + 输入框 | 直接输入图中字符 |
| 点选验证码 | 图片 + 点击 | 在图片上依次点击字符位置，可撤销/清空；坐标按**原图分辨率**回传 |
| 短信验证码 | 输入框 | 服务端已下发短信 |
| TOTP 动态口令 | 输入框 | 也可在设置中填入 TOTP 密钥自动生成 |
| 二次认证 | 输入框 + 「跳过二次认证」 | 跳过对应上游的 `$` 前缀语义 |
| 外部登录（CAS/OAuth2） | 打开链接 + 粘贴回调地址 | 在浏览器完成登录后把回调 URL 粘回 |

若弹窗关闭（扩展弹窗被关、Android 界面退出），验证码请求仍然有效：
重新打开界面即可继续应答，超时时间 5 分钟。

## 5. 诊断

- **连通性自检**：对服务器 `host:port` 做 TCP 探测，返回延迟，用于排查网络与端口问题。
- **日志**：界面下方实时日志（含上游协议日志，密码已脱敏）；"复制诊断信息"会带上版本、状态与最近日志。
- 命令行诊断（与浏览器无关）：

```bash
rvpn-core --selftest vpn.zju.edu.cn:443
rvpn-core --once '{"cmd":"hello"}'
rvpn-core --tcp 127.0.0.1:1080 --log-file /tmp/rvpn.log   # 供自研前端接入
core/test/e2e_dummy_login.py                              # 完整协议自检（无需真实账号）
```

## 6. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 登录提示"用户名或密码错误" | 确认使用**上网账号**（学号/工号）与上网密码，而不是统一身份认证的二次密码；非校园网需先连上校园网或 VPN 前置通道 |
| 一直显示"正在连接" | 检查服务器地址/端口是否可达（用「连通性自检」）；校外网络可能无法直连 RVPN 服务器 |
| 登录成功但校内网站打不开 | 校内站点需要 DNS 也走 RVPN：确认未开启"禁用远端 DNS"；若是 EasyConnect 且服务端未下发资源，请勿关闭内置 ZJU 规则 |
| 公网访问变慢 | 关闭 `proxyAll`（默认关闭）；RVPN 模式下仅命中规则的流量走 VPN |
| 代理未生效/扩展报"内核未找到" | 未安装 `rvpn-core`：运行 `packaging/linux/install.sh`，或设置 `RVPN_CORE_BIN` 指向它 |
| 提示 "Specified native messaging host not found" | 原生消息宿主清单未注册：重新运行安装脚本；自编译内核时用 `browser/scripts/run-linux.sh` 启动 |
| Android 上 RVPN 模式无效 | 需要 WebView 支持 `PROXY_OVERRIDE`（WebView 78+）；在系统设置中更新 Android System WebView |
| 会话频繁掉线 | 关闭省电优化；Android 上保留前台服务通知；桌面端保持核心进程运行 |

## 7. 安全与隐私

- 代理仅监听 `127.0.0.1`；核心拒绝非回环监听地址。
- 密码保存在浏览器本地：桌面为 `chrome.storage.local`，Android 为 SharedPreferences，**未额外加密**；
  可在设置中关闭"记住密码"，改为每次手动输入。
- `client_data.json` 权限 `0600`，包含 aTrust 会话票据；删除它即可强制重新认证。
- 断开 RVPN 时一定会清除代理设置，避免"代理仍在但核心已退出"导致无法上网。
